# مراجعة قانونية — قالب عربي بلا محتوى

تطبيق ويب ثابت (بلا خادم) للمراجعة القانونية بالعربية. كل بيانات المستخدم تُحفظ على جهازه (IndexedDB).

## الملفات
- `index.html` — التطبيق كاملًا. **للتخصيص عدّل كائن `APP_CONFIG` في أول السكريبت** (الاسم، الكلية/القسم، حرف الشعار، اللون).
- `generators.js` — مولّدات الأسئلة (فراغات من نص الكتاب) وجلسات المراجعة المتباعدة.
- `books/index.json` — قائمة الكتب الظاهرة في المكتبة. `books/<id>.json` — كتاب (باب ← قسم ← فصل ← مبحث ← فقرات).
- `questions/<id>.json` — بنك أسئلة الكتاب (اختياري). إن لم يوجد يُولَّد تدريب فراغات تلقائيًا.
- `sw.js` + `manifest.webmanifest` + الأيقونات — للعمل دون اتصال والتثبيت على الهاتف.
- `tools/build_sample.py` (خارج المجلد) — يحوّل بيانات النموذج القديم إلى الكتاب التجريبي.

## إضافة كتاب جاهز
1. ضع `books/my-book.json` (البنية في دليل التسليم) و`questions/my-book.json` اختياريًا.
2. أضف سطره في `books/index.json`: `{ "id": "my-book", "title": "...", "subtitle": "...", "file": "books/my-book.json", "questions": "questions/my-book.json" }`
3. ارفع التعديل إلى GitHub.

## إضافة كتاب من ملف txt (من المستخدم نفسه)
زر «استيراد كتاب (txt)» في المكتبة. العناوين تُكتشف من الكلمات: باب / قسم / فصل / مبحث (أو مطلب / فرع)؛ ما عداها فقرات. تظهر معاينة قبل الحفظ. يُحفظ الكتاب على جهاز المستخدم فقط.

## النشر على GitHub Pages
Settings → Pages → Deploy from branch → `main` / root. ارفع محتويات هذا المجلد كما هي. عند تغيير ملفات الواجهة ارفع رقم `VER` في `sw.js` ليصل التحديث للمستخدمين.

## النسخ الاحتياطي
من الإعدادات: «حفظ نسخة (ملف)» و«استعادة من ملف»، وزر ربط مجلد (كروم/إيدج فقط) لحفظ النسخة داخل مجلد يختاره المستخدم.

## كتل المحتوى الغنية (جديد)
الفقرة في ملف الكتاب إما سلسلة نصية (تُعرض كفقرة عادية) أو كائن بنوع `t`:
`p` و`h2` و`h3` و`h4` (حقل `h` = HTML مبسّط)، `ul` و`ol` (`items`)، `co` (إطار: `k` النوع `def|legal|case|why|idea|note|ex|ruling`، `l` العنوان، `h` النص، `q:true` للنص النظامي)، `table` (`head` و`rows`). لكل كتلة `id` ثابت اختياريًا. يُنقّى HTML عند التحميل (وسوم تنسيق فقط).

## وضع التعديل
الإعدادات ← «وضع التعديل». يعدّل الطالب النص المعروض في أي كتلة؛ يُحفظ بمعرّف الكتلة في بيانات الجهاز (مفتاح `edits`) ويدخل النسخة الاحتياطية، ولا يمسّ ملف الكتاب. «استعادة أصل الفصل» تعيد الأصل.

## الأسئلة
`type`: `mcq` (خيارات متغيرة العدد) أو `tf` (صح/خطأ أو نعم/لا؛ يبقى ترتيب الخيارين ثابتًا). `anchor`: عبارة من الفقرة المصدر تُطابَق بعد التطبيع؛ إن وردت في فقرة واحدة بالضبط ظهر زر «اقرأ الفقرة» بعد الإجابة. `answerStatus`: `derived-from-text` = الإجابة مستنتجة من نص الشرح وتنتظر مراجعة المؤلف.

## أدوات التحويل
`tools/html_to_book.py` يحوّل ملف شرح HTML دلالي إلى كتاب JSON + أسئلة خام، و`tools/build_madar_questions.py` يبني ملف الأسئلة من جدول الإجابات ويفحص أن كل مرساة تظهر مرة واحدة.
